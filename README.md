# Passive Memory Recorder

Минимальный Android-рекордер для постоянной фоновой записи с телефона.

## Что делает v1

- пишет микрофон в фоне через Android microphone foreground service;
- сохраняет AAC/M4A в `Music/PassiveMemoryRecorder`;
- автоматически переходит в новый файл примерно раз в час без обычного `stop -> start`;
- пока запись активна, показывает тихое постоянное системное уведомление;
- когда запись выключена, показывает одно заметное постоянное уведомление с двумя действиями:
  - **ВКЛЮЧИТЬ ЗАПИСЬ**;
  - **НЕ НАПОМИНАТЬ**;
- если выбрать **НЕ НАПОМИНАТЬ**, предупреждение больше не появляется;
- как только запись снова успешно запущена, подавление предупреждения сбрасывается — следующая остановка снова покажет предупреждение;
- после перезагрузки/обновления приложения запись автоматически не стартует: Android запрещает запуск microphone foreground service из `BOOT_COMPLETED`. Вместо этого появляется предупреждение с кнопкой запуска.

В приложении намеренно нет STT, AI, аккаунта, облака, базы данных и сторонних библиотек.

## Формат записи

- контейнер: MPEG-4 (`.m4a`);
- кодек: AAC;
- mono;
- sample rate: 44.1 kHz;
- bitrate: 48 kbit/s;
- ротация: около 22 MB, то есть примерно один час.

Ориентировочный объём при непрерывной записи: около 0.5 GB/сутки до учёта небольшого container overhead.

## Установка через Android Studio

1. Установить актуальный Android Studio.
2. Клонировать репозиторий:

   ```bash
   git clone https://github.com/bakinngTray/passive-memory-recorder.git
   cd passive-memory-recorder
   ```

3. Открыть папку проекта в Android Studio.
4. Дождаться Gradle Sync. Проект использует:
   - Android Gradle Plugin 9.4.0;
   - Gradle 9.6;
   - JDK 17;
   - compile/target SDK 36.
5. На Samsung включить **Developer options -> USB debugging**.
6. Подключить телефон по USB и подтвердить RSA fingerprint.
7. Нажать **Run** в Android Studio.
8. На телефоне разрешить:
   - микрофон;
   - уведомления.
9. Нажать **ВКЛЮЧИТЬ ЗАПИСЬ**.

Записи появятся в:

```text
Internal storage/Music/PassiveMemoryRecorder/
```

## Сборка из терминала

Если установлен JDK 17, Android SDK 36 и Gradle 9.6:

```bash
gradle :app:assembleDebug
```

APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Установка по ADB:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`-r` обновляет приложение поверх существующей установки.

## Поведение уведомлений

### Запись включена

Тихое ongoing-уведомление:

```text
Пассивная память: запись активна
[Остановить]
```

### Запись выключена

High-importance ongoing-уведомление со звуком/вибрацией:

```text
Пассивная память выключена

[ВКЛЮЧИТЬ ЗАПИСЬ]  [НЕ НАПОМИНАТЬ]
```

**НЕ НАПОМИНАТЬ** означает именно то, что написано: приложение не возвращает это предупреждение само. Оно снова становится активным только после того, как пользователь успешно включил запись.

Важно: пользователь может отдельно запретить уведомления приложению в системных настройках Android. Приложение не может обойти этот системный запрет.

## После перезагрузки

Современный Android не позволяет приложению автоматически запустить foreground service с доступом к микрофону из `BOOT_COMPLETED`. Поэтому после перезагрузки приложение показывает предупреждение, а запись запускается одним нажатием на **ВКЛЮЧИТЬ ЗАПИСЬ**.

Если до перезагрузки было выбрано **НЕ НАПОМИНАТЬ** и запись после этого не включалась, приложение уважает этот выбор и не показывает предупреждение.

## Samsung / энергосбережение

Foreground service предназначен для длительной фоновой записи. Если One UI всё же ограничивает приложение, разрешите ему неограниченную фоновую работу в настройках батареи приложения.

## Ограничения v1

- Если пользователь делает **Force stop** приложения в Android Settings, Android блокирует приложение целиком; оно не сможет показать предупреждение до следующего ручного запуска.
- Телефонные звонки и другие приложения, захватывающие микрофон, могут конфликтовать с записью. При ошибке recorder останавливается и показывает обычное предупреждение о выключенной записи.
- Ротация файлов основана на размере, поэтому это примерно час, а не ровно 60:00.
