# Passive Memory Recorder

Минимальный Android-рекордер для постоянной фоновой записи с телефона.

## Что делает v0.3

- пишет микрофон в фоне через Android microphone foreground service;
- сохраняет AAC/M4A в `Music/PassiveMemoryRecorder`;
- каждые 60 минут закрывает текущий файл, сразу начинает следующий и запускает выгрузку закрытого файла;
- пока запись активна, показывает тихое постоянное системное уведомление;
- когда запись выключена, показывает одно заметное постоянное уведомление с двумя действиями:
  - **ВКЛЮЧИТЬ ЗАПИСЬ**;
  - **НЕ НАПОМИНАТЬ**;
- если выбрать **НЕ НАПОМИНАТЬ**, предупреждение больше не появляется;
- как только запись снова успешно запущена, подавление предупреждения сбрасывается — следующая остановка снова покажет предупреждение;
- просит исключить приложение из оптимизации батареи для устойчивой длительной записи;
- после перезагрузки/обновления приложения запись автоматически не стартует: Android запрещает запуск microphone foreground service из `BOOT_COMPLETED`. Вместо этого появляется предупреждение с кнопкой запуска;
- позволяет один раз выбрать папку Google Drive через системный Android folder picker;
- после завершения каждого `.m4a` (в том числе после часовой ротации) пытается отправить **все** готовые локальные записи в выбранную папку;
- если сети нет или копирование не удалось, локальные файлы остаются без изменений;
- локальная запись удаляется только после полного успешного копирования в выбранный Drive provider;
- при следующем завершении файла снова проверяет весь накопившийся backlog.

В приложении по-прежнему нет STT, AI и базы данных. Для Google Drive не нужен отдельный Google API key или OAuth-клиент: используется системный Storage Access Framework и сохранённый доступ к выбранной пользователем папке.

## Настройка Google Drive

1. Установить/открыть Google Drive на телефоне и войти в нужный Google-аккаунт.
2. В Passive Memory Recorder нажать **ВЫБРАТЬ ПАПКУ В GOOGLE DRIVE**.
3. В системном выборе папки открыть Google Drive и выбрать, например, папку `PassiveMemory/Audio Inbox`.
4. Подтвердить доступ к папке.

После этого приложение само запускает короткую фоновую попытку синхронизации каждый раз, когда закрывается очередной аудиофайл. Если папка ещё не была выбрана, записи просто остаются локально.

## Формат записи

- контейнер: MPEG-4 (`.m4a`);
- кодек: AAC;
- mono;
- sample rate: 44.1 kHz;
- bitrate: 48 kbit/s;
- сегментация: по времени, 60 минут на файл.

Ориентировочный объём при непрерывной записи: около 0.5 GB/сутки до учёта небольшого container overhead.

## Установка через Android Studio

1. Установить актуальный Android Studio.
2. Клонировать репозиторий:

   ```bash
   git clone https://github.com/bakinngTray/passive-memory-recorder.git
   cd passive-memory-recorder
   ```

3. Открыть папку проекта в Android Studio.
4. Дождаться Gradle Sync. Проект использует:
   - Android Gradle Plugin 9.4.0;
   - Gradle 9.6;
   - JDK 17;
   - compile/target SDK 36.
5. На Samsung включить **Developer options -> USB debugging**.
6. Подключить телефон по USB и подтвердить RSA fingerprint.
7. Нажать **Run** в Android Studio.
8. На телефоне разрешить:
   - микрофон;
   - уведомления;
   - исключение из оптимизации батареи.
9. Нажать **ВКЛЮЧИТЬ ЗАПИСЬ**.

Записи появятся в:

```text
Internal storage/Music/PassiveMemoryRecorder/
```

## Телефонные звонки на Samsung

Обычное стороннее Android-приложение не имеет системного доступа к обоим каналам телефонного разговора. Поэтому обычные телефонные звонки следует записывать встроенной функцией Samsung Phone.

На поддерживаемой региональной прошивке:

```text
Телефон → ⋮ → Настройки → Запись вызовов → Автозапись вызовов → Все вызовы
```

Android отдаёт телефонному звонку приоритет на аудиовходе. Во время звонка наш фоновый recorder может получить тишину, но не должен перехватывать микрофон у самого звонка. В будущий processing pipeline нужно отправлять оба источника: файлы Passive Memory Recorder и штатные Samsung call recordings.

## Поведение уведомлений

### Запись включена

Тихое ongoing-уведомление:

```text
Пассивная память: запись активна
[Остановить]
```

### Запись выключена

High-importance ongoing-уведомление со звуком/вибрацией:

```text
Пассивная память выключена

[ВКЛЮЧИТЬ ЗАПИСЬ]  [НЕ НАПОМИНАТЬ]
```

**НЕ НАПОМИНАТЬ** означает именно то, что написано: приложение не возвращает это предупреждение само. Оно снова становится активным только после того, как пользователь успешно включил запись.

Важно: пользователь может отдельно запретить уведомления приложению в системных настройках Android. Приложение не может обойти этот системный запрет.

## После перезагрузки

Современный Android не позволяет приложению автоматически запустить foreground service с доступом к микрофону из `BOOT_COMPLETED`. Поэтому после перезагрузки приложение показывает предупреждение, а запись запускается одним нажатием на **ВКЛЮЧИТЬ ЗАПИСЬ**.

Если до перезагрузки было выбрано **НЕ НАПОМИНАТЬ** и запись после этого не включалась, приложение уважает этот выбор и не показывает предупреждение.

## Ограничения

- Если пользователь делает **Force stop** приложения в Android Settings, Android блокирует приложение целиком; оно не сможет показать предупреждение до следующего ручного запуска.
- Системный поток телефонного разговора недоступен обычным third-party приложениям; для него используется Samsung Phone call recording.
- Между часовыми сегментами есть очень короткий `stop/start`, поэтому теоретически возможен небольшой разрыв звука на границе часа.
- Загрузка в Drive идёт через Android DocumentsProvider. Успешное завершение копирования означает, что файл полностью передан выбранному Google Drive provider; дальнейшую сетевую синхронизацию самого provider выполняет приложение Google Drive.
